\# WasteWise AI



\## Intelligent Waste Classification and Segregation Using Deep Learning



WasteWise AI is an AI-powered waste classification system designed to identify different types of waste from images and provide intelligent segregation and disposal recommendations.



\## Project Status



🚧 Under active development.



\## Planned Pipeline



Image

→ Preprocessing

→ Deep Learning Model

→ Waste Classification

→ Confidence Analysis

→ Disposal Recommendation



\## Planned Models



\- Custom CNN — baseline

\- ResNet50 — transfer learning

\- Comparative evaluation



\## Evaluation



The models will be evaluated using:



\- Accuracy

\- Precision

\- Recall

\- Macro F1-score

\- Weighted F1-score

\- Confusion Matrix

\- Per-class performance
